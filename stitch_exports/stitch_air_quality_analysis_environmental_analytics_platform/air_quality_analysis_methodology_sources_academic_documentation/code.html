account_balance Source Authority & Data Ingestion Modality

Primary ground truth records are structured according to the open data archives of the Central Pollution Control Board (cpcb.nic.in) in collaboration with regional State Pollution Control Boards (DPCC Delhi, MPCB Maharashtra, KSPCB Karnataka, and WBPCB West Bengal). Telemetry ingestion models are parsed from official CPCB 4:00 PM Daily National Bulletins combined with CAAQMS automated continuous samplers (calibrated and simulated for this analytical platform).

Mathematical Formulation: Sub-Index Algorithm

Piecewise Linear Interpolation conforming to IIT Kanpur & CPCB 2014 Framework

Eq. 2.1-A
Ip = [ (IHI - ILO) / (BHI - BLO) ] × (Cp - BLO) + ILO
AQI = max(I1, I2, I3, ..., In)
Mandatory Validation Criterion: An overall AQI can only be calculated if data is available for at least three pollutants, out of which one must strictly be either PM2.5 or PM10.
Cp: Measured pollutant concentration
Ip: Computed sub-index for pollutant p
BHI, BLO: Breakpoint concentration caps
IHI, ILO: AQI category indices corresponding to B

Computational Pipeline Flow

Sequential mathematical execution stack in data engine

1
Raw Telemetry & IST Normalization

Ingests station-level feeds, standardizing Asian/Kolkata timestamps to UTC ISO-8601 representation.

2
Physical Bound Check & Optical Clamping

Enforces instrument thresholds. Values < 0 µg/m³ flagged as sensor fault; optical scattering baseline calibrated.

3
24-Hour Truncated Arithmetic Mean

Applies CPCB's 16-hour minimum valid data rule (≥ 66.7% daily temporal completeness required per diurnal cycle).

4
Piecewise Linear Sub-Index Interpolation

Locates breakpoint brackets (BLO, BHI) for each valid pollutant and computes individual Ip values.

5
Dominant Pollutant & Final AQI Maxima

Verifies 3-pollutant condition; extracts peak sub-index as final AQI, logging the governing pollutant identifier.

Project Scope Boundaries & System Limitations

Academic research demarcation, scientific constraints, and evaluation boundaries

warning_amber Pre-Integration Demo Status

Simulated Telemetry Architecture

Live telemetry readings shown across dashboard cards and active maps utilize simulated statistical sampling curves derived from historical CPCB distributions. This software build serves academic demonstration purposes and must not be used as certified legal or statutory regulatory environmental data.

insights Deterministic Analytics (No AI/ML)

Explainable Mathematical Modeling

The platform intentionally omits opaque deep learning or black-box predictive models (e.g., LSTM, XGBoost) to maintain total algebraic explainability. All aggregations represent deterministic arithmetic formulations compliant with Indian National Air Quality Index protocols.

map Spatial Interpolation Limits

Discrete Node Representation

The 42 CAAQMS stations represent discrete spatial sample points. Continuous surface modeling across intermediate non-monitored zones via Inverse Distance Weighting (IDW) or Ordinary Kriging remains demarcated outside the scope of this minor project evaluation build.

air Meteorological Dependencies

Secondary Planetary Boundary Layer Metrics

Atmospheric dispersion factors including Planetary Boundary Layer Height (PBLH), wind vector trajectories, and thermal inversion levels are synchronized via secondary ERA5 demo re-analysis parameters rather than on-site ultrasonic anemometers.
